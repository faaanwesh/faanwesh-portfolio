# Anwesh Fago — Network & Infrastructure Engineer

A bespoke, responsive portfolio focused on network engineering, data center operations, infrastructure deployment, and automation.

## Built with
- Semantic HTML, custom CSS, vanilla JavaScript
- Inline SVG network topology illustration
- No framework, build step, external runtime dependency, or tracking scripts
- GitHub Actions + GitHub Pages deployment

## Run locally
Open `index.html` in a browser, or run a local static server:

```bash
python -m http.server 8000
```

## Deploy
The workflow in `.github/workflows/pages.yml` deploys the repository root to GitHub Pages on every push to `main`.

In repository Settings → Pages, set Build and deployment → Source to **GitHub Actions**.
